# Sousa Nebula for Zed

A subtle dark-purple theme for [Zed](https://zed.dev), designed to match the Sousa Nebula terminal palette.

## Palette

- Background: `#11111b`
- Surface: `#181825`
- Elevated surface: `#1e1e2e`
- Foreground: `#cdd6f4`
- Purple accent: `#cba6f7`
- Subtle border: `#252536`

## Install for development

1. Clone this repository.
2. Open Zed's command palette.
3. Run `zed: install dev extension`.
4. Select the cloned repository directory.
5. Choose **Sousa Nebula** from the theme selector (`ctrl-k ctrl-t`).

## Repository structure

```text
zed-theme/
├── extension.toml
└── themes/
    └── sousa-nebula.json
```
